# Project Memory

## Core
Project: Friends Sports Academy, swimming academy in Mugalivakkam, Chennai.
Design: High-energy sports aesthetic. Bebas Neue (headings), Inter (body).
Auth: Supabase Email OTP (6-digit code). NEVER use mobile OTP (costs).
DB: Supabase 'profiles' table, auto-populated by trigger on signup.
